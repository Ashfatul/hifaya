## 📖 অ্যাপ পরিচিতি (Overview)

**Hifaya (হিফায়া)** হলো শিশুদের সুরক্ষা (Protection), সুস্থতা, প্রশান্তি এবং পিতা-মাতার প্রতিদিনের আমলের জন্য একটি আধুনিক, স্নিগ্ধ ও পূর্ণাঙ্গ ইসলামিক ওয়েব ও PWA অ্যাপ্লিকেশন।

শিশুর জন্মের পর বদনজর (Evil Eye / حسد / আল-আইন), ভয় পাওয়া, অনিদ্রা, অতিরিক্ত কান্না বা অসুস্থতার সময় সহীহ হাদিস ও কোরআনের আলোকে বিশুদ্ধ দোয়ার হরকতসহ আরবি পাঠ, সহজ বাংলা উচ্চারণ, অর্থ এবং আমলের সঠিক সুন্নতি নিয়ম একসাথে উপস্থাপন করে এই অ্যাপ।

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- 👶 **স্মার্ট সর্বনাম ও ব্যাকরণ পরিবর্তন (Dynamic Pronoun Switcher)**:
  - শিশুর লিঙ্গ নির্বাচন: **কন্যাশিশু (Girl)**, **পুত্রসন্তান (Boy)**, অথবা **একাধিক / যমজ (Multiple/Twins)**।
  - হাদিসের দোয়ার ব্যাকরণ স্বয়ংক্রিয়ভাবে সমন্বয় হয়:
    - ছেলে: `أُعِيذُكَ` (*উ‘ঈযুকা*), `أَرْقِيكَ` (*আরক্বীকা*)
    - মেয়ে: `أُعِيذُكِ` (*উ‘ঈযুকি*), `أَرْقِيكِ` (*আরক্বীকি*)
    - একাধিক: `أُعِيذُكُمَا` (*উ‘ঈযুকুম্বা*), `أَرْقِيكُمْ` (*আরক্বীকুম*)

- 🔍 **বড় ও স্পষ্ট হরকতযুক্ত ফন্ট (Scalable Typography Widget)**:
  - চোখের আরামদায়ক বড় ফন্ট সাইজ কন্ট্রোলার (`A-` / `A+` / রিসেট)।
  - আরবিতে `Amiri` এবং বাংলায় `Hind Siliguri` ফন্ট।

- 📊 **দৈনিক হেফাজত রুটিন চেকলিস্ট (Daily Routine Tracker)**:
  - **🌅 সকালের হেফাজত** (ফজর পরবর্তী ৩ কুল ও নববী সুরক্ষা)।
  - **🌇 মাগরিবের সতর্কতা** (সূর্যাস্তের সময় শিশুদের ঘরের ভেতরে রাখার বিশেষ সুন্নত ও দোয়া — *বুখারী: ৩২৮০*)।
  - **🛌 রাতের ঘুমের আমল** (আয়াতুল কুরসী ও ঘুমের মাসনূন আমল)।

- 🔢 **ডিজিটাল তসবীহ কাউন্টার (Interactive Digital Tasbih)**:
  - নির্দিষ্ট পাঠসংখ্যা (১ বার, ৩ বার, ৭ বার) অনুযায়ী স্মুথ ট্যাপ কাউন্টার।
  - কাঠবিদ্ধ তসবীহর মতো আলতো সাউন্ড ও হ্যাপটিক ভাইব্রেশন ফিডব্যাক।
  - আমল শেষ হলে সুমধুর কর্ড চাইম এবং কনফেটি সেলিব্রেশন।

- 🔊 **অফলাইন অডিও ও ঘুমের সাউন্ড (Offline Audio & Baby Sleep Hum)**:
  - প্রয়োজনীয় সূরাসমূহের মিষ্টি তিলাওয়াত অডিও।
  - শিশুকে দ্রুত ঘুমাতে সহায়তা করার জন্য ইন্টারনেট ছাড়াই ব্যাকগ্রাউন্ডে ব্রাউন-নয়েজ সুদিং সুর।

- ⏰ **স্মার্ট রিমাইন্ডার ও নোটিফিকেশন (Gentle Reminders)**:
  - সকাল, মাগরিব ও রাতের আমলের জন্য ব্রাউজার অ্যালার্ট।

- 🗂️ **সহজে সম্পাদনাযোগ্য JSON ডাটাবেজ (`data/duas.json`)**:
  - কোনো কোড পরিবর্তন না করেই যে-কেউ সরাসরি JSON ফাইলে নতুন দোয়া যোগ করতে বা সম্পাদনা করতে পারবেন।

- 📱 **অফলাইন ও PWA প্রস্তুত (Offline First)**:
  - লোকাল স্টোরেজে প্রতিদিনের আমলের হিস্ট্রি ও বুকমার্ক সংরক্ষিত থাকে।

## 🚀 ইনস্টলেশন ও লোকাল রান (Getting Started)

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install
```

### ২. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করুন।

### ৩. প্রোডাকশন বিল্ড:
```bash
npm run build
npm run start
```

### ৪. লিন্ট চেক:
```bash
npm run lint
```
